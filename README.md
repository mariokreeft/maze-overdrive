# Maze / Overdrive

Standalone arcade maze game with pellets, power-ups, keys, doors, timed traps, bombs, destructible crates and four enemy behaviors. Includes sound, touch controls, local high scores and increasingly difficult levels.

## Play locally

Open `public/index.html` in a browser. No dependencies or build step are required.

## Controls

- Arrow keys or WASD: move
- Space: place bomb
- Shift: dash
- P / Escape: pause
- M: toggle sound

## Vercel

Import this repository into Vercel. Use the **Other** framework preset, leave the build command empty, and set the output directory to `public`. The included `vercel.json` configures the static output directory.
